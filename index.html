PROJECT · DEPLOYED · IN USE

Marks Automation for a Government Primary School

A browser extension and a hosted server that take a school's student roster from the government marks portal, build the marks sheets teachers fill in, and then enter the marks back into the portal. Teachers write on printed sheets. Scanning reads the handwriting, and any value with low confidence is highlighted so the teacher can correct it by hand.
